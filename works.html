Does it catch the problems?

I tested it on example order confirmation pages where I already knew every problem. Partners set up their pages in different ways, so the test covers both kinds. Each page was checked two ways: by fixed rules alone, which can only read pages set up exactly the standard way, and by the AI agent, which can also read pages set up differently. Both use the same rules to decide whether a page is ready.

Loading results...

It never says "ready" when it isn't sure. If a page can't be read with confidence, the answer is "not ready" and a person takes a look.

I built the example pages myself, so this shows the checker works as designed. The next step would be testing it on real partner pages. The sample store and the paste option on the check page are a start.

Ready for a team to run

  • Every check is logged with its cost and speed, and an alert goes out if the agent struggles or quality drops.
